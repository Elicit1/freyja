# Freyja agent 小说创作与需求澄清验收

日期：2026-10-11。统一助手仍为 `core-assistant`，Profile 升级到 v3。

## 变更

- 直接聊天可以创作、续写和润色小说，文本保存在会话中，无需启动分镜制作。
- 原制作入口保留，更名为“小说转视频准备”，拆解、资产、分镜模式与参考素材流程继续可用。
- 新增必需工具 `request_user_input`：每组 1–3 个问题，选项带说明与推荐标记，始终支持自由填写。没有默认答案或自动继续。
- 问题、等待状态和回答保存在原有消息与检查点表；刷新后恢复问题，回答继续同一 Run，可在后续轮次再次提问。
- 结构化回答校验 Run、工具步骤、问题集合与选项；过期卡片不能推进当前任务，重试复用原提交结果。纯文本回答和“停止并发送”保留。
- 聊天名称改为“Freyja agent”。聊天、新建会话和制作表单居中；窄屏聊天覆盖宠物，避免遮挡输入。问题出现时定位卡片，历史在窗口内滚动。
- v2 配置升级只补齐必需工具与版本，保留模型、形象、启停、可选工具和执行预算，不重新合并旧制作配置。无新依赖或数据库迁移。
