## 核心场景

- **两个开关**：对 REF2VA → FL2VA → REF2VA 的相邻镜头组合，分别运行关/关、关/开、开/关、开/开四组，断言当前镜仅在对应开关开启时获得上一镜尾帧或下一镜首帧。
- **已配置帧优先及快照**：提交后修改分镜 Prompt、seed、首帧，执行仍使用原快照；已配置首尾帧保留，不调用自动抽帧。
- **后序 FL2VA**：当前镜不等待尚未执行的下一镜新视频；没有旧视频时省略尾帧，不形成循环等待。
- **单在途任务**：阻塞第一个模拟视频生成请求，同时再次调用消费者；第二批保持排队，最大同时在途计数为 1。释放首个请求后第二批正常执行。
- **整批取消**：第一镜成功、第二镜阻塞、第三镜排队时，从第二镜的子任务入口取消。断言第一镜结果 URL 不变，第二镜线程退出，第三镜从未调用生成接口，批次状态为 CANCELLED。
- **取消后的其他批次**：上游确认取消后，全局槽位释放，下一个独立批次成功执行，验证取消不会永久终止消费者。
- **上游未确认**：本地中断、所有排队项取消，全局槽位保持；后续领取不触发生成。显式记录停止核实依据后才释放槽位。
- **全选与层级选择**：剧集、场景、镜头组、单镜范围混选取并集，排除指定镜头，不产生重复项目；ALL 展开完整候选。
- **幂等与变更**：相同提交返回同一批次；相同请求 ID 内容不同或预检后输入改变时拒绝提交，事务不留下额外批次或占用。
- **归档恢复**：模拟视频已生成但 MinIO 归档失败，重试只调用归档接口，视频生成总调用次数保持为 1。
- **数据边界**：无效关键图绑定不创建任务；19 位 ID 在结构化配置响应中保持字符串；原始含数字 ID 的 JSON 不暴露给前端解析。
- **网关帧角色**：仅提供尾帧时不误接成首帧；额外参考图不改变首尾帧角色；同一张图可明确用于两个角色。H3 工作流组装回归通过。
