# 场景文字设计与动态图片挂载

## 使用流程

1. 在场景资产的「空间与基本信息」填写名称、原文或创作者要求，点击「AI 设计场景文字」。支持 API 模型与外部 AI 手工通道；预览修改后采纳，保存中文设定和配套英文场景生图词。无需先上传图片。
2. 在分镜配置选择场景，点击「挂载场景参考槽位（可稍后补图）」；也可在提示词工作台的候选池添加无图场景。挂载后占据固定的 `<Picture N>` 编号，再生成分镜提示词。
3. 在场景资产补充空间参考图/封面，或更换该位置的图片。动态挂载的分镜下次渲染使用最新图片，无需逐镜重新挂载。
4. 已规划但未补图的槽位允许保存及生成提示词，提交渲染时会指明缺图的 Picture 编号并拒绝提交，不能跳过槽位造成编号错位。

中文场景设定是空间事实依据，英文场景生图词是视觉表现参考。换图应符合已有文字布局；布局或陈设变化时应同步修改文字并重新生成分镜提示词。换图不会修改已生成的视频。

## API 扩展

沿用 `/res/scene/derive-prompts`、`/derive-prompts-stream`、`/derive-prompt-package`、`/parse-derived-prompt` 和任务中心 `/ai/tasks/scene-prompt`。

- 请求新增 `designDescription: true` 启用场景文字设计。返回新增 `description`（必填、中文），同时输出 `scenePrompt`、`negativePrompt`。
- 普通提示词衍生省略该标记，返回的 `description` 被清空，不会意外覆盖已有文字。
- 手工结果校验的请求必须保留相同标记；该标记参与上下文指纹。
- `/res/scene/options` 补充返回 `description`。

`refImages` 中的动态场景槽位示例：

```json
{
  "id": "stable-scene-slot",
  "sourceType": "SCENE",
  "sourceId": "2032095628944588801",
  "name": "办公室（空间参考图）",
  "usageRole": "SCENE",
  "bindingMode": "ASSET_LINK",
  "sourceSlot": "SCENE_REFERENCE"
}
```

- `sourceSlot` 只能明确指定 `SCENE_REFERENCE` 或 `SCENE_COVER`，不会自动回退到另一张图。
- `imageUrl` 为当前解析出的预览值，动态挂载以资产 ID 与位置为准；支持为空。
- 不指定 `bindingMode` 或指定 `SNAPSHOT` 的旧数据保持固定 URL。提示词工作台提供显式切换为「跟随空间参考图/封面」的入口，保持槽位 ID 和顺序。
- 动态引用仅允许当前短剧或公共库中启用的场景。所有业务 ID 保持字符串。
- 首尾帧生图请求新增有序 `refImages`。提供此字段时优先解析并冻结它；否则沿用显式 `referenceImageUrls`，未指定 URL 时采用分镜保存的参考槽位。

## 快照与失效规则

单镜/批量视频在提交时解析最新 URL，将副本内的槽位转为 `SNAPSHOT`，保存在视频队列任务中，不回写分镜动态配置。预检后换图会要求重新预检。排队期间换图不影响已提交任务；下一次提交使用新图。

首尾帧生图在进入渲染调度等待前冻结参考 URL，并在渲染任务中保存请求快照。媒体清理引用检查包含视频批量任务快照，防止仍被任务使用的旧图被清理。

提示词指纹包含场景中文描述、生图词、类型、时段、氛围、资产 ID 与图片位置及槽位顺序，不包含动态图片 URL 和补图状态。仅替换图片可复用提示词，修改文字或参考编排需重新生成。

字段扩展使用现有 JSON 列及已有描述字段，无需数据库结构迁移。
