# 自然转场与接舞

## 默认：完整动作完成后再过渡

先让一个有意义的动作或动作短句完成，重量承接、转向结果、接触交接或延展目标可读，再借下一动作、乐句释放或空间关系自然换到下一镜。完整动作可以包含多个步骤，不把每一次抬手、跨步、躯干波动都拆成一镜。

“完成”是主要动作任务与结果已交代、支撑关系成立，可发生在连续行进与换重心中，不要求双脚落定、收成某个固定脚位、站直或面向镜头摆姿势。余势、呼吸、衣摆、持续张力和准备下一动作可以继续；延展到位也不必先垂手完全放松。需要完整展示落地的动作仍须保留其重量承接，不能为了等模型时长而凭空增加停顿。

把当前动力质感作为跨镜继承的一部分：前镜指尖延伸尚在持续、胸廓仍在展开或身体正在可控回弹时，后镜承接同一方向、速度趋势和张力发展，不因换镜把身体复位成无张力站姿再重新蓄力。只有实际编舞安排了释放/停顿时才改变。支持合理的局部隔离，不能为保持全身参与强加额外摆动。

关键手形、视线落点与可见表情也属于交接状态。后镜从前镜仍在发展的表演接续，不无意改成另一手势、盯向摄影机或重新微笑；变化须有动作/表达依据，并在方案中交代。换机位后的画面左右重新核对，身体方向与看向的实际对象保持相容。

在用户没有另行改变此要求时，避免硬切和整段素材直接硬接。先判断能否保持一段连续运镜；确需多个镜头时为每个边界设计可执行的过渡。动作匹配、相同姿势或提示词写了“smooth transition”都不自动证明转场自然。

## 可选衔接办法与优先关系

先找完整动作后的自然边界；有意义的机位变化再比较下列方法。表内是选择依据，不是每个镜头都必须换一种转场。

| 办法 | 适用情形 | 前后镜与素材要求 | 实现与取舍 |
| --- | --- | --- | --- |
| 连续运镜换取景 | 同一动作/空间持续，只需从全身到中景、正面到三分之四等可达视点 | 保持舞者世界坐标、支撑、动作相位、摄影机路径和速度连续 | 优先在同一次生成中完成；分文件延展须有真实尾帧/延展支持并验收，不能靠文件直拼冒充长镜头 |
| 动作完成点的轻柔过渡 | 一个短句完成、落脚/收势已交代，下一镜开始新短句 | 结果可辨，下一镜继承身体/空间状态；构图变化有观看目的 | 可用实际制作的桥接片段，或在适合的稳定/低速区做短叠化；保持原母带时间，避免为过渡额外停住 |
| 遮挡桥接 | 场景或既定动作里有真实经过的前景/身体遮挡，可短暂覆盖镜头 | 遮挡物、覆盖范围、方向、速度、曝光和重新显露后的站位相容 | 设计进入遮挡→在覆盖区衔接→离开遮挡，必要时生成中间桥接；不临时变出柱子/道具，不用大面积遮挡隐去必须看见的落地 |
| 动势与相位匹配 | 连续旋转、移动或长动作确需换视点，完整动作后切换不可行或另有表达 | 精确对应同一运动相位、支撑、世界方向、画面方向与速度，机位和轴线可读 | 是备选而非默认；要借可行桥接/遮挡或实测无感拼接实现。仅写“match cut”或对齐一张姿势图仍可能硬跳，不能直接当验收通过 |
| 摄影机运动桥接 | 实际运镜本就在横移、跟随或小弧线运动，需要延展观察角度 | 前后运动方向、速度、视差、焦段观感、景别和落幅接得上 | 对动作读得清优先；不默认甩镜、强模糊或高速推拉来掩盖素材不匹配 |
| 构图/视线引导的桥接 | 动作已完成，注意力自然移向新的演员或身体局部 | 先让动作结果成立，再以视线、手势或相机揭示关联对象；目标已经存在 | 可在同镜连续揭示，或生成有空间依据的中间视点；不随机插入无关空镜和新角色 |
| 短叠化 | 时间/情绪柔和转换，或动作完成后的低速、稳定构图适合融合 | 人物比例、位置、背景、光色和运动需可融合，保留完整动作及用户锁定端点 | 由真实生成/剪辑能力实现；时长按素材与音乐选择，不设固定每镜转场秒数。高速四肢易重影，不把叠化当通用修复 |
| 声音连续辅助 | 所有视觉衔接都可保留一条连续母带，必要时保留环境声尾音 | 音轨不重启、不重复、不删漏，时间与声音层实际对齐 | 只能辅助视觉，不能单凭音乐连续便声称消除硬切；跨镜混音需实际工具实现 |

用户明确要求保留可见的某个动作、脚部接触或末帧时，不得借遮挡、插镜、叠化裁尾绕开。没有自然切点且资源不足时，保留长动作目标，选择可行延展或调整摄影覆盖；需要用户决定的真实约束冲突再说明，不偷偷截断动作。

## 整段转场的变化与重复

由 AI 结合当前动作的完成与延续、音乐/歌词的发展、观看重点、构图和实际空间条件选择过渡。前景真实经过时可以遮挡桥接；注意力转向已有的手势或另一舞者时可以连续揭示；乐句释放且画面可融合时可以考虑短叠化。选择取决于当下条件，不把任一范例变成所有边界的默认模板，也不逐镜向用户请求选择。

连看相邻边界与整段方案：是否无意反复用同一遮挡、同方向环绕、推近再拉远或叠化？“手臂擦镜”和“前景遮挡”若都表现为相同覆盖—显露过程，不能仅因名称不同就算已有变化。没有动作、音乐或观看目的依据时，重新选择适配机制，并同步调整摄影路径、出入状态、素材需求和提示词；不要只追加“转场丰富多样”。

音乐回归、视觉母题或明确的空间连续可以支持重复，简述其用途即可。用户锁定的转场或一镜到底优先保留。不规定转场种数、比例、最多连续次数或固定轮换；长镜本身成立时无需为了变化拆镜。变化不能以新增道具、摆拍停顿、遮掉落地、破坏轴线或改变母带时间为代价。实际条件只支持一种自然方式时如实说明限制，不虚构其他方法已经实现。

## 每个边界写一张衔接卡

规划中至少写清：

1. **完成条件与边界**：哪个主要动作目标已完成、支撑关系是否成立，观众最后看到什么；仍未完成时说明为什么必须采用连续运动衔接。
2. **前镜出状态**：母带时间、演员站位/朝向、支撑与摆动腿、手臂、动势、呼吸与持续延伸/张力、相机位置/方向/速度、构图和光线。
3. **后镜入状态**：继承什么、下一动作从哪一相位开始，延伸与松紧怎样继续；新视点如何到达，不重做已经完成的动作或为了换镜重新起势。
4. **过渡机制与声音锚点**：保持连续镜、动作完成后的桥接、遮挡、相机延展或可用叠化；说明适配当前动作/构图和真实乐句/事件的理由，必要时说明与前后转场的变化或有意重复关系。
5. **素材与实现**：哪些真实帧/Take/桥接素材、是否需要前后余量、由哪个实际生成或剪辑能力实现；未执行写“待制作/待后期”。

这些是创作记录，不是新的 FREYJA 转场 API 字段。用户只要方案时写可执行计划；用户已授权制作时按实际能力实现并验证。

## 母带时间不能因转场漂移

桥接或叠化通常需要素材余量。两个参与过渡的画面应覆盖同一段母带全局时间，不先按互不重叠的区间生成，再把尾首随意重叠导致整片变短或动作提前。每个取用片段分别保存源入点、出点、母带位置和重叠范围。

例如仅作数学说明：在全局 `[9.8,10.2)` 做0.4秒融合，需要A、B都具有这段母带对应的有效画面；不是拿A的9.6–10.0秒与B的10.0–10.4秒强行叠成同一时刻。示例不规定实际转场长度，也不代表这些素材已存在。

桥接镜本身占用原母带中的时间窗，不能无依据插入额外秒数、重复一拍或拉伸原曲。原生帧网格、Take 实测长度、转场余量和最终剪辑覆盖分别计算；增加余量前核对部署资源，不承诺模型对任意秒数和相位精确命中。

FREYJA 普通整段拼接不提供自然转场保证，也不自动做时间线重叠。当前工具只支持直拼时，交付完整素材、衔接卡及待后期清单，明确尚未满足“不硬切”的成片要求；不能擅自交直拼片并声称已完成。若同一次生成和实际能力能直接完成连续观察，可以优先这样实现。

## 编写提示词与验收

前镜写清动作完整落点与真实出状态，后镜从承接状态继续；桥接镜写具体过渡过程，不只加“smooth”“seamless”。各业务分镜依然各自按 H3 的局部 `[Shot 1]` 和实际输入编译，不把整个镜头组强塞成一次不受控多切镜。

实际看片先看完整动作是否被截掉，再逐帧查看边界附近的支撑脚、肢体位置、运动速度、持续张力/延伸、呼吸与余势、相机视差、脸/服装、曝光、背景几何和遮挡连续性；叠化另查重影、多肢与人物漂浮。注意前镜延伸到位、后镜忽然垂手松掉后又重复抬起等重置。最后以正常速度结合母带看节奏是否自然。需要严格动作同步时复核实际落点，桥接和换音轨都不自动修复原素材的错拍。

再连看整段，检查实际视觉过程是否与所选变化或有意重复一致；文字里列出多种方法不能代替看片。只有计划、首尾帧或提示词通过检查时，报告“转场已设计”；实际素材和最终合成通过验证后，才报告“自然转场已完成”。
