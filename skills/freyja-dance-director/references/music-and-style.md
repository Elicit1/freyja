# 音乐依据、拍网与舞种选择

## 分清测量、听感与推断

记录三类依据：媒体探测得到的时长/采样率；实际试听得到的鼓组、音色、摇摆和乐句；工具提出的 BPM/起音候选。每项可以是“实测”“试听判断”“自动估计”“用户给定”“待测”。用户给定的数据可作为规划依据，但不写成已经独立验真。

分析目标片段，同时确认它在原母带中的源入点。先辨认它由什么组织：稳定律动、乐句与旋律、人声、声部变化、独立声音事件或自由动态。确有主脉冲时，再判断反拍、切分、弱起、速度变化和段落。起音列表包含装饰音，不能直接当成拍点列表；能量增加不自动等于副歌；第一个鼓点不必是第一强拍。

音频类型、身体舞种和编舞组织方法分别决定。按 [可选编舞方法](choreography-methods.md) 比较合适的组织方式；固定计数不是默认条件。只有采用节拍/计数方法时才记录拍号与分组，分组可按实际的三拍、五拍、七拍等结构或动作任务选择。无稳定脉冲时以事件、乐句和动态区间标记，不强制补拍网。

有歌词时另记录文本来源与实际演唱时间的证据状态，按 [歌词与动作关联](lyrics-to-movement.md) 核对句意与人声锚点。用户给定歌词、LRC 或经核对的转写可用于规划；自动转写保留不确定处，LRC 行时间不自动等于逐字时间。下述分析脚本不转写歌词，也不生成歌词与音频的对齐结果。

全局母带时间为 `T`。某镜无变速地覆盖母带 `[a,b)`，镜内时间 `t=T-a`；音频片段自身从零开始时仍记录其母带源入点。固定 BPM 的计数方案每拍 `60/BPM` 秒，N拍区间为 `N*60/BPM` 秒；选择八拍时才取N=8，4/4中它对应两个小节。弱起或从乐句中间进入时，以确认的相位标记，不能把片段零点当第一拍。非节拍方法使用真实事件时间和区间，无需此公式。

建议分析表：

| 源区间 | 音频组织特征/可靠度；适用时附拍网 | 实际听到的声音特征 | 主要事件/乐句/动态锚点 | 可选编舞方法与动作质感 |
| --- | --- | --- | --- | --- |
| 使用真实时间 | 待试听或已确认；有脉冲时说明速度歧义 | 鼓、贝斯、旋律、人声、切分、音色、环境事件等 | 实际音频中的事件或待试听 | 有依据的组织方法、弹性、延展、停顿等 |

## 可选本地分析工具

`scripts/analyze_audio.py` 依赖 Python 3.10+、NumPy、FFmpeg 和 FFprobe。当前运行环境缺少依赖时说明缺项；可继续给暂定方案，不为运行脚本改变平台或凭空声称听过音乐。脚本只接受本地文件；远程/平台素材先通过已有真实媒体访问能力取得合法可读文件，不把 URL 填成本地路径。

```text
python scripts/analyze_audio.py "歌曲.wav" --out "音乐分析.json"
python scripts/analyze_audio.py "歌曲.mp3" --start 12 --end 44 --out "片段分析.json"
python scripts/analyze_audio.py "歌曲.wav" --bpm 120 --beat-anchor 12.375 --start 12 --end 44 --out "校正拍网.json"
```

`--start`/`--end` 是源文件时间（秒）；输出的事件和拍点也是源文件全局时间。`--beat-anchor` 是已确认的某个拍点的全局时间，不声明它是小节强拍；只有和 `--bpm` 一起提供才可使用。用户标定的固定拍网仍需核对实际音乐是否变速。

脚本的 JSON 提供：来源 SHA-256、媒体元数据、分析范围、起音、短时能量、候选速度、估计或用户标定的拍网及警告。自动网格的状态始终为待试听确认，不自动输出拍号、强拍、乐句、曲风或舞种。特征以约 10 毫秒步长计算，但窗口、编码、寻址及演奏会影响落点，不能据小数位承诺毫秒准确。

很短、弱起音、长铺底、强切分、自由速度或变速音乐可能没有可靠 BPM。候选含半速/倍速时试听确认主律动；不要仅因分数最高就把它宣布为曲子的唯一速度。读取分析窗口内的拍点，不按一个固定 BPM 无限外推到全曲。对音景、朗诵和事件主导音频，可直接采用相应方法，不为使用分析脚本而强行使用它的节拍候选。图表或波形只能辅助定位，不能替代实际听感。

## 推荐舞种的方法

速度只是一个维度。综合主律动的重心、摇摆/切分、鼓与贝斯的问答、旋律线条、空间感、演唱语气及段落能量，并考虑演员条件。下面是选择方向的起点，不是曲风与舞种的一一对应规则。

| 已观察到的声音特征 | 可比较的舞蹈方向 | 身体表达与注意 |
| --- | --- | --- |
| 明确后拍、贝斯律动、放克切分 | Funk groove、Locking、Popping 或 Hip-hop groove | 弹性重心、隔离和停点；锁定/震动不是每拍都加 |
| 连续四拍底鼓、循环低音、细密踩镲 | House、Club groove；Disco 特征明显时再比较 Waacking | 连续脚下弹性与方向变化；快节奏脚步不必伴随复杂手部 |
| R&B/Neo-soul 的拖拍、细密切分、留白 | Hip-hop groove、Jazz-funk、流动型 Contemporary fusion | 松紧与延迟到达；不要把所有动作做成同样的匀速 |
| 流行歌曲段落明确、钩子突出、重拍易辨 | Pop choreography、K-pop performance、Jazz-funk | 设计一个可辨认动作母题，副歌回归时变体，避免只拼热点舞步 |
| 长旋律、弦乐/钢琴延展、呼吸明显 | Contemporary、Lyrical；有具体语汇需求再考虑 Ballet fusion | 重心转移、躯干延展与呼吸，不默认每首钢琴曲都跳芭蕾 |
| 真实拉丁/加勒比节奏型，重音结构与步法相容 | Salsa、Bachata、Cha-cha 或其他对应方向 | 先确认具体律动，不用“拉丁风”混用不同基础步和拍型 |
| 三拍或复合拍的旋转/摇摆感 | Waltz-inspired、Contemporary phrase 等 | 以真实拍群组织动作，不套四拍八拍模板；双人关系需可成立 |
| 民族乐器或传统曲式 | 与确切音乐背景相符的传统舞蹈或现代融合 | 先核对具体文化/舞种语汇；不能用服装和手势替代识别依据 |
| Ambient、散板、弱脉冲 | Contemporary、身体剧场、慢速即兴 | 用呼吸、音色进入与实际乐句定位，允许没有稳定 BPM |

每个推荐写清“为何适配、动作会怎样、在哪里可能失真”。例如：听到清晰四拍底鼓和连续低音时，可把 House 作为候选，因为连续脚步和弹性膝部能承接主律动；若旋律与人声更适合上身表演，可以将 Pop choreography 作为更稳的方案。不能把例子的声音特征当成当前音频已有事实。

默认给一个主推荐和一两个备选即可。用户指定传统舞种、指定偶像舞、指定专业难度或混合风格时遵循其选择；只在有具体冲突时说明如何调整动作和镜头，不因模型难生成就擅自改舞种。
