# 平台执行与交付验收

用于把音乐画面方案落实到 FREYJA 分镜、渲染与交付。以下是当前接入边界；执行时先发现实际开放的工具，已升级的能力按新接口核实。

## 先核实可用能力

| 事项 | 当前处理方式 |
| --- | --- |
| 项目、资产和分镜卡片 | 按 guide 确认授权项目与父级容器，查询/复用人物、造型、场景、道具和关键图；使用真实 ID、媒体 URL 与业务枚举 |
| 角色声音 | 配音中心维护角色音色和克隆，不是任意音乐上传、自动节拍分析或多轨剪辑工作台 |
| 外部音乐输入 | 当前有参考音频配置不代表已有任意音频文件上传工具。确认真实传输和片段准备途径；本地路径不会自行变成平台 URL，不能借图片上传接口传音频 |
| H3 参考音频 | 使用 `audioUrl` 和必填 `referenceType`；最多 3 段，每段 2–15 秒、总长不超过 15 秒，以真实媒体探测为准。不用 `usageMode`/`sourceType` 冒充音频字段 |
| 渲染 | 仅在授权范围通过当前开放工具发起；写分镜、读 Skill 不会自动开始视频生成。检查模型范围、算力和帧对齐，避免无变化重试 OOM |
| 导出 | 可导出当前绑定 Take 的 ZIP，或按业务顺序完整拼接 MP4，保留各段音轨，无音轨补静音；不会等待正在生成的新 Take |
| 精确后期 | 当前普通导出请求没有每镜入出点、母带轨、对白定位或自动压低配乐的混音参数。不能承诺自动裁齐、踩点、铺原曲或对嘴修复；有实际外部 FFmpeg/剪辑工具和授权时才执行 |

20 秒音乐可以作为整片规划与最终母带；参考输入 15 秒限制不等于最终成片只能 15 秒。需要短参考时保留原文件，通过真实可用工具准备合规片段并记录全局源入出点，不伪报时长、丢弃尾段或假造音频地址。

## 保存与生成

1. 保留项目画幅、视觉风格、用户锁定和已确定台词；画幅未确定按 guide 和业务选项处理。原有剧情仅改配画面时，不为套用流程重写故事。
2. 拟定音乐时间表与每镜完整剧本，按实际人声与动作窗口估时。动作、对白、旁白自然写入 `scriptContent`，不要写已退役的独立对白/旁白字段。未确定景别/运镜可用业务允许的 `AUTO`，不把计划中的音轨字段编进 API。
3. 按画面约束选择真实支持的模式：`REFERENCE_MODE` 用 `prompt`、有序 `refImages` 和所需 `refAudios`；`FIRST_LAST_FRAME` 用 `videoPrompt` 和实际可用首尾帧输入，不假定该工作流也接收外部音频。写最终 H3 卡片前读官方 Skill 及模式参考。
4. 人物、造型、场景、道具与关键图按 guide 复用，参考图用途从当前下拉选项选取，不自造枚举。检查关键图是单个瞬时状态，不把整个乐句的一串动作画在一张图上。媒体引用编号跟最终输入顺序一致。
5. 更新前读真实记录及 `editFingerprint`，业务 ID 保持字符串。关键保存后读回核对剧本、`duration`、模式、提示词、人物/造型和音频关系；请求冲突先刷新，超时沿用稳定请求 ID，不重复创建。
6. 已授权生成时再提交并跟踪任务。先对关键同步镜头核验方案，按实际问题修正，避免在未解决同类时长/口型问题时盲目批量重渲染。用户仅要方案或 Skill 时，不启动媒体任务。

## 声音使用注意事项

- 连续音乐优先保留一条母带及其全局时间；不能每镜重新从曲首播放，也不能把独立生成的配乐当作天然无缝。单段转场的尾音、混响和编码延迟都要实际试听。
- 母带已经含有人声、对白、音效时，先标出已有层，避免模型再生成一遍或后期重复叠加。歌词不当作新的对白逐句念出；对白也不默认改成演唱。
- 音乐与对白叠加时以清楚听懂用户要求的台词为目标；是否压低配乐、何时进出以及与环境声的关系应写成混音计划，只有可用工具实际处理后才报告已完成。没有分轨时不能保证只降低伴奏而保持原曲人声不变。
- 非叙事配乐通常不随摄影机摇移而左右乱跑，也不因切到远景就自动变小。画内音源如收音机、舞台或路边乐手，才按听点、距离、方向和遮挡设计变化；特意采用的主观听觉按创作者意图表达。
- 对白、脚步、碰撞和空间底声遵循 guide 的 `references/sound-design.md`：远近、进出画和遮挡要有物理与叙事依据，不因出画就静音。避免音乐、音效把关键台词盖住，检查爆音、突变、重复、底噪和无意静音；没有测量时不编造响度数值或峰值达标结论。

## 逐镜与整片验收

用实际可用的媒体探测和试听/观看完成以下检查；工具不能验证的项目明确写为待验，不用“配置正确”代替“成片已验证”。

- **时长与定位**：记录每个 Take 的真实 URL/版本，实测帧率、帧数、视频/音频时长、时间戳及首尾静音；与母带区间和计划入出点比较，核对每一切点及累计偏移。补帧、转码和最终导出后再检查实际成品。
- **音乐与人声**：原曲是否按用户选择保留；乐句有没有重播、跳过、断裂、变调或不合意补尾；对白/歌词是否完整、重复或缺字，角色是否正确。跨镜试听接缝，整片检查，不只抽查第一镜。
- **嘴型与动作**：在实际时间点看发声口型、停顿换气、关键动作与音乐重音；旁白不误绑画内角色，人物演奏/舞步不虚假宣称准确。替换音轨后须再验同步。
- **视觉与剪辑**：身份、服装、空间、道具、轴线及动作起落可衔接；没有为裁时长丢掉指定尾帧、落脚或最后一个字。以用户要求的节奏评价，不能仅以每镜有视频为通过。
- **导出选择**：确认当前绑定的是所选合格 Take，按实际顺序核对遗漏镜头和总长。只做整段拼接时报告真实片长，不声称自动对齐原曲。

完成报告写清“已规划”“已生成并验收的分镜素材”“已完成最终音画合成”中的实际阶段、关键实测时长及仍待处理的具体问题。当前工具只能完成素材时，提供按母带时间排列的剪辑/混音清单和真实素材位置，说明最终对齐待后期，不把超长拼接片冒充严格定长的音乐成片。
