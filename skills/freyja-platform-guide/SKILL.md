# FREYJA 平台创作指南

帮助创作者把故事组织成可制作的分镜，并通过明确的剧本和合适的图像约束保持人物、环境与表演连续。遵循创作者已确认的剧情、画幅、风格、布局和锁定项；建议不能覆盖明确要求。

## 规范分层原则（Rules vs. Recommendations）

- **必须遵循的硬性铁律**：收录于本指南（`SKILL.md`），具有一票否决权与最高约束力，AI 规划与编排时必须无条件执行；
- **创作建议与最佳实践**：详细的组合建议、选型决策树、优缺点对比表、业界避坑技巧与视听接戏经验，详见参考文档：
  - 视觉模式权衡、参考图搭配与避坑建议：读 [references/visual-references.md](references/visual-references.md)
  - 镜头剧本、视听控制、时长估算与动作接戏建议：读 [references/storyboard-workflow.md](references/storyboard-workflow.md)
  - 业务架构、资产关系与机位画面视听控制法则：读 [references/architecture.md](references/architecture.md)

## 创作必须遵循的硬性铁律（Mandatory Production Rules）

### 1. 核心 Skill 加载与依赖铁律（Mandatory Skill Loading）
AI 在进行短剧规划、分镜设计与生图/视频提示词编写时，**主要且仅读取以下两大核心 Skill 即可，其他 Skill 不得读取**，防止规则冲突与上下文干扰：
- **`h3-prompt-writing`**：MiniMax H3 官方提示词规范（官方段落结构、标签语法、媒体引用编号及声场格式）；
- **`freyja-platform-guide`**（本指南）：平台视听控制、硬性守恒律、生图物理常识与交付质检规范。
> **严禁读取其他 Skill（如 `cinematography`、`camera-direction` 等）**。

### 2. 重要角色必配参考图与三视图细节铁律（Character Asset Requirements）
- **重要角色必配参考图**：凡在剧中出现的重要角色（包括所有主角、配角；除纯背景无台词路人群众外），**都必须具备完整的人物参考图（`ResCharacter` / `ResCharacterLook` 资产图）**，严禁无参考图盲猜抽卡出镜；
- **三视图（Three Views）不可或缺**：参考图必须包含正视图（Front）、侧视图（Side）与后视图（Back），确保多机位、旋转与反打镜头下三维空间拓扑与外观结构绝对一致；
- **关键细节特写（Key Details）**：必须提供面部五官特写、发型妆容、服饰材质纹理与专属配饰，杜绝中近景与特写画面中细节变形；
- **人物设定图严禁手持道具（No Handheld Props in Character Sheet）**：人物身份与造型设定图**严禁手持任何道具、武器、器具或物品**，人物双手必须保持自然垂落或空手标准姿态。严禁将手持剑、枪、杯、扇等道具画入人物设定图，否则会导致“道具与主体强行绑定”，角色在所有无需持物的镜头（如睡眠、用餐、空手行走）中都会被迫一直拿着该道具，造成恶性穿帮；
- **重要道具单独生成专属参考图（Independent Prop Asset Reference）**：剧情中特别重要的道具（如专属武器、定情信物、关键法器、案件凶器等），**必须作为独立的道具资产（`ResProp`）单独生成专属参考图**：
  - **必须具备完整三视图（Three Views）**：包含正面视图（Front View）、侧面视图（Side View）与立体截面/俯视图（Top/Perspective View），锁定道具的三维几何结构与厚度/长度参照，杜绝多机位变形；
  - **底色必须为纯白或透明（White or Transparent Background）**：底色必须为**纯白色背景（Solid White）或真实 Alpha 透明背景（Transparent PNG）**，严禁带有自然环境、桌面、阴影渐变或装饰性杂质，确保特征提取绝对纯净；
  - **核心结构细节展示（Key Details）**：必须提供握持部位（如缠绳护手）、铭文刻字、材质纹理与机械卡扣等关键细节特写，保障特写镜头高保真；
  - **分镜解耦调度**：在分镜需要角色使用道具时，通过多模态槽位同时引用人物图与独立道具图，实现主体与道具的自由解耦与状态流转。

### 3. 禁止全剧单一模式一刀切铁律（Anti-Homogenization Rule）
- **严禁全剧统一机械使用同一种生成模式**：严禁在整部剧或整场戏中将所有分镜一律设为 `FIRST_LAST_FRAME` 或一律设为 `REFERENCE_MODE`；
- **因镜动态选型**：必须依据每个分镜的视听叙事任务、动作幅度与资产构成权衡选型：
  - 连续镜头组动作顺接、微距人机交互咬合点、明确终点闭环定格 -> 必须采用 `FIRST_LAST_FRAME`；
  - 多角色同框对话与群戏对峙、大范围摄影机运镜、多实体资产并存、剧烈走位动作 -> 必须采用 `REFERENCE_MODE`。

### 4. 参考图跨镜头强连续性三大守恒律（Cross-Shot Continuity & Three Invariants）
参考图作为整段剧情多镜头时空演进的视觉基准锚点，跨镜头叙事必须严格遵循三大守恒律：
1. **实体依附与操作拓扑守恒**：主体与客体之间的依附关系（持有手别、装配附着点、佩戴方式与受力朝向）具备绝对时空继承性。除剧情显式声明物理状态转移外，后续镜头严禁发生对称颠倒、随机漂移或无交代突变；
2. **空间相对位姿与 180° 轴线守恒**：多机位切换、景别推拉或反打切镜时，主体间相对空间坐标、视线朝向矢量与运动矢量必须严格遵守 180° 动作轴线原则，严禁无视听过渡的镜像倒置与视线逆转；
3. **环境实体与建筑外立面形制风格守恒**：同一物理时空复现的环境实体（建筑立面、空间结构、材质纹理、装饰标识、色彩基调）具备绝对同一性，严禁切镜重构或美术风格割裂。

### 5. 画内与画外内容提示词处理铁律（In-Frame vs. Off-Screen）
- **画外内容绝对不得进入生图提示词**：严禁在正向提示词中写“某某在画面外”、“门外传来敲门声（画外）”，避免模型强行画出画外人物或画框边缘生成畸变肢体与鬼影；
- **更绝对不能作为负面提示词**：严禁在负向词中写诸如 `xxx is outside the frame`、`某某在画面外`，负面提示词提及画外角色会反向污染语义空间甚至诱发该角色出镜；
- **最高执行法则：直接不描述即可（Silent Omission）**：生图提示词仅描述画框内真实可见的实体；画外角色、画外动作与画外声源直接彻底忽略、完全不提；画外台词与声音仅由剧本台词或声场描述承载。

### 6. 首尾双帧协同物理连续性铁律（仅限同时提供首尾帧时）
- **机位轴线与景别严格锁定**：同一镜头内严禁首尾两端视角翻转、机位反打或景别跳变；
- **尾帧必须同源重绘**：尾帧**绝不能**脱离首帧独立文生图盲抽，必须以首帧为底模通过局部修改生成，人脸、衣服、光向与环境硬装必须强硬继承；
- **动作幅度与时长物理可达**：单镜时长（3–4秒）内仅容纳单一连贯微动作，严禁动作跨度过大导致视频中段发生“融化拉扯（Morphing）”或肢体鬼畜；
- **提示词只描述中间运动过程**：首尾帧提示词绝不要重复首尾两端的静态状态，只描述中间运动过程与相机轨迹。

### 7. 画面默认无文字化与伪汉字一票否决铁律（Text-Free & Pseudo-Character Rejection）
- **默认无文字化设计**：提示词中严禁要求生成特定中文句子或招牌长文本，必须改用材质、纹理、几何光影与意象替代（如“烫金纹饰实木匾额”、“无字纯纸张信笺”）；
- **关键短标识规范**：仅允许使用阿拉伯数字（如 `201`）或极简大写英文（如 `OPEN`, `CAFE`）；核心契约或长文本道具采用画面留白，后期图层排版真实文字；
- **伪汉字一票否决**：画面中一旦出现形似汉字但不可读的乱码、异形字或外星偏旁符文，必须判定为不合格资产，执行局部重绘或重生。

### 8. 生图前置人机交互物理常识核查铁律（Physical Affordance & Grounding）
在发起任何图片生成前，必须预先核查人机交互逻辑，并将物理细节显式写入生图提示词：
- **握持接触咬合点**：明确哪只手接触物体的哪个确切结构部位（如“右手五指紧扣皮革缠绳刀柄”、“左手平托青瓷杯底”），杜绝手握刀刃、倒持器具或手指穿模；
- **功能端朝向安全**：刀刃朝外、枪口朝向安全或目标、杯口朝上，严禁刃部切己或枪口对准操作者自身；
- **重力支撑与承重受力面**：坐卧必须有清晰受力载体（如“稳稳坐在红木高背椅上，臀部与大腿贴合椅面”），杜绝“空气坐”或“双脚沉入地板”；桌面放置有清晰接触阴影；
- **道具人体比例协调**：提供人体参照锚点，杜绝比例失调。

### 9. 平台操作与数据完整性铁律（Platform & Data Integrity）
- **雪花 ID 保持字符串**：业务 ID 原样保持字符串（`string`），严禁转换为 JavaScript 浮点数以防精度丢失截断；
- **统一剧本承载**：台词、旁白、动作和表情统一写入 `scriptContent`，严禁使用已废弃的分镜独立对白/TTS 字段；
- **并发控制**：修改记录前读取最新 `editFingerprint`，提交对应的 `expectedFingerprint`；
- **严禁代码正则猜谜**：AI 从原文与已确认素材中提取结构化事实，未知状态留空或明确继承，严禁依靠后端编写脆弱的关键词或正则字符串盲猜；
- **视听机位控制**：全景交代宏观空间，中景容纳肢体动作与道具咬合点，特写聚焦情绪微表情与器物细部；未锁定时机位与运镜保持 `AUTO`，严禁仅为了切换特写视角而切断连贯动作拆碎镜头；
- **长对话上下文回读**：上下文被压缩且不确定前镜详情时，严禁盲猜，必须调用详情工具（`get_shot`、`list_shots`）读回事实。

## 交付前置完整检查清单（Pre-Delivery Verification）

每个交付的分镜卡片必须逐项核对通过以下 10 项铁律：
1. [ ] **叙事表演与画内画外**：动作、表情与时长匹配；生图提示词与负向提示词中绝无画外内容，画外直接不描述；
2. [ ] **模式动态权衡**：严禁全剧模式一刀切，根据动作顺接/微距交互 vs 群戏/大运镜正确选型；
3. [ ] **角色资产与道具解耦**：出镜主角与配角均配备三视图与细节特写人物参考图（除纯路人外）；人物设定图严禁手持道具（双手保持自然垂落/空手姿态）；特别重要的道具已单独作为独立资产生成专属参考图（且必须具备三视图、纯白或透明底色以及关键结构细节特写）；
4. [ ] **跨镜三大守恒**：实体依附拓扑严格继承（持物手别不反转）；符合 180° 轴线（无交代不镜像倒置）；环境实体立面风格统一；
5. [ ] **首尾帧输入**：优先单首帧；双帧协同需机位景别锁定、尾帧同源重绘、提示词只描述中间运动过程；
6. [ ] **画面无文字化**：无伪汉字乱码（一票否决），招牌与信件采用材质替代或留白后期排版；
7. [ ] **物理交互逻辑**：握持部位咬合精准、功能端朝向合规、坐卧有承重支撑（无空气坐）、放置有接触阴影；
8. [ ] **素材与图号**：模式与素材匹配，提示词精确绑定 `<Picture X>`，无图号混淆；
9. [ ] **声音纯净**：音色属于正确角色，画外说话人不强行入画，默认无背景音乐；
10. [ ] **持久化核对**：读回真实模式、视频提示词、帧 URL 与人物 ID，确保数据落库。
