# FREYJA 平台创作指南

帮助创作者把故事组织成可制作的分镜，并通过明确的剧本和合适的图像约束保持人物、环境与表演连续。遵循创作者已确认的剧情、画幅、风格、布局和锁定项；建议不能覆盖明确要求。

## 先理解项目，再选择工作阶段

先读项目、大纲、目标镜头组、相邻镜头及可复用资产，再修改目标记录。不要只根据孤立的一句分镜重建人物或场景。

- 理解短剧、剧集、场次、镜头组、镜头及资产关系：读 [references/architecture.md](references/architecture.md)。
- 选择生成模式、参考图组合、关键图用途及首尾续接：读 [references/visual-references.md](references/visual-references.md)。**制作或调整分镜视觉素材时必须读这一份。**
- 编写有表情与动作的镜头剧本、安排时长、检查成片：读 [references/storyboard-workflow.md](references/storyboard-workflow.md)。

通过 FREYJA MCP 工作时先 `list_skills`，再 `read_skill(name="freyja-platform-guide")`；用返回的字符串 `versionId` 和 `read_skill_file` 读取本技能所需 `references/` 文件。发生版本冲突时重新读取目录及正文，不混用不同版本。其他 Agent 环境直接读取本技能目录中的文件。

本技能负责平台方法。人物/造型设定图按目录加载 `character-sheet-design`，分镜规划按需加载 `camera-direction`、`cinematography`。写 MiniMax H3 视频提示词时加载 `h3-prompt-writing` 及对应参考：首尾帧用 `references/base-en.txt`，参考模式用 `references/ref-en.txt`。技能缺失时说明缺项，不声称已遵循未读规范。

## 每个完成的分镜都要做出的决定

1. **叙事**：这个镜头完成什么动作、对白或情绪变化？归属哪个场次、哪个连续镜头组？
2. **表演**：谁在画内/画外，穿哪个造型，在哪里，看向哪里，做什么，表情如何变化？把当镜状态明确写入 `scriptContent`。
3. **模式**：需要控制准确起止画面时选 `FIRST_LAST_FRAME`；需要多图约束人物、环境与构图时选 `REFERENCE_MODE`。按模型实际能力选择，不能假定同一请求可混用两种输入协议。
4. **视觉依据**：每个需要稳定画面的完成镜头应有适用的真实图像依据。可以是人物图与场景图组合，也可以是一张足够完整的关键图，或首尾帧模式下已核验的帧图；不用为凑数量机械加图。缺图时标记待制作，文字草稿不等于已有参考图。
5. **交付**：保存正确模式的最终视频提示词、图像及有序引用，明确时长；读回核对。只有剧本、只有图片、只有图片 Prompt 都不能声称已经完成视频卡片或成片。

## 素材选择的核心经验

- **人物图 + 场景图可以一起使用**：人物图约束身份/造型，场景图约束空间布局、材质和环境；提示词分别说明职责。
- **完整关键图可以独立使用**：若已清晰、正确地包含本镜所有必要人物身份、造型和场景信息，可不再加入重复的人物图与场景图。仍保留正确的业务人物关联。
- **关键图缺什么才补什么**：人物太小、遮脸、换装或缺少目标人物时补人物/造型图；环境布局不足时补场景图。冲突图片先消除冲突，更多图片并不保证更稳定。
- **当镜表情写在剧本中**：稳定身份设定不能代替当前表演。明确可见的眼神、眉眼、嘴角、姿态与变化触发，避免只有“愤怒”“难过”等抽象标签。
- **图片有职责和时间位置**：构图参考不一定是首帧，首帧也不等于动作结果图。明确哪些必须保留、哪些允许变化，避免把图片冻结成整段视频。

## 平台操作约束

- 业务 ID 原样保持字符串，不转浮点数字；既有 ID、媒体 URL、枚举值从实际记录、工具 Schema 与业务选项读取。
- `resSceneId` 与 `resKeyframeId` 是互斥的主视觉关联；需要补充图时使用 `refImages`。人物 `characterRefs` 与图片槽位弱绑定各有作用，省略人物参考图不等于删除人物。
- 台词、旁白、动作和表情统一写入 `scriptContent`，不用已废弃的分镜独立对白/TTS 字段。声音属于人物身份资产；画外说话人不应被强行安排出镜。
- 外部 MCP 负责读取知识、业务 CRUD、上传真实图片和关联，不提供内部生图/视频/TTS 执行。生成图片使用当前环境已授权的图片工具，视频制作使用工作台或明确可用的生产能力；不要虚构工具或生成状态。
- 修改已有记录先读最新 `editFingerprint`，提交对应 `expectedFingerprint`；重试使用稳定 `requestId`。保留未修改字段及创作者锁，引用数组提交会整体替换。
- 非提示词内容用简体中文；提示词遵循模型/技能语言规范，原文对白保留原语言。默认无背景音乐，保留对白、环境声与必要音效；明确要求配乐时服从用户及当前生产能力。
- 不让 Java 通过关键词或正则猜测人物状态、身份、镜头语义。AI 从原文和已确认素材提取结构化事实，未知状态留空或明确继承，不补造剧情。
