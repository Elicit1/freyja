# 生成模式与视觉参考

## 两种模式的选择与字段

| 模式 | 合适的目标 | 最终视频提示词 | 视觉输入 |
| --- | --- | --- | --- |
| `FIRST_LAST_FRAME` 首尾帧模式 | 明确控制开场构图和落点，让视频完成两端之间的连续动作 | `videoPrompt` | 首帧 `previewImageUrl`；按需要及模型能力提供尾帧 `endFrameImageUrl`；待生图时分别用 `firstFramePrompt/endFramePrompt`。 |
| `REFERENCE_MODE` 参考图模式 | 结合身份、造型、环境、道具或关键图生成当前表演，允许模型按职责重构镜头 | `prompt` | 实际有序的 `refImages`，有需要再配 `refAudios`。 |

首尾帧模式并非每镜都必须提供两张图；具体必需输入和分辨率/时长限制以所选模型能力为准。首尾帧生图与视频生成是不同阶段，图片 Prompt 不能代替动态视频 Prompt。

模式应显式保存。切换时重新检查目标模式的提示词和输入，不能依赖另一个模式遗留字段来完成本次请求。参考模式把关键图标为 `FIRST_FRAME` 是该参考图的用途，不会自动切换 `generationMode`。

## 每镜参考图的决策

先看图像内容、清晰度与覆盖范围，再作决定；只有文件名、提示词或“关键图”标签时，不能声称已确认图中身份与场景正确。

| 当前素材情况 | 建议组合 | 必须说明 |
| --- | --- | --- |
| 有清晰人物/当前造型图与独立场景图 | 人物/造型图 + 场景图 | 人物图管脸、体型和衣着；场景图管空间与材质，不从空场景中增加人物。 |
| 关键图完整包含正确人物、造型和环境 | 可以仅用这张关键图 | 哪些人物和空间元素要保留，本镜动作和表情怎样变化；不重复加图。 |
| 关键图中脸太小、被遮挡、造型不符或缺人物 | 关键图 + 缺失人物/造型图 | 新图补充哪个角色及约束；先解决同一人物的换装/面孔冲突。 |
| 关键图人物清楚，但环境只剩模糊背景 | 关键图 + 场景图 | 场景图补空间事实；关键图若只管人物，不要求复制其背景。 |
| 只有空场景，当前镜头有必须识别的人物 | 场景图 + 对应人物/造型图 | 空场景不能稳定尚未建立的人物身份。 |
| 只有文字关键图或失效 URL | 标记待制图或补档 | 不提交假 URL、空图片槽位，也不称作已有图像约束。 |

完整关键图替代人物图和场景图，是当前画面约束的选择；人物 `characterRefs`、造型、场次归属仍要正确保存。省下的是冗余图像输入，不是删除故事实体。

先消除参考冲突：同一人物不同服装、同一空间不同门窗布局、相反光向、互斥道具状态应明确当前采用哪一种。需要多图时分配不重叠的职责；不要简单要求“严格保留所有图片的一切”。

## 参考图绑定与顺序

- 每项有真实 `imageUrl` 和明确 `sourceType`。资产来源还要真实 `sourceId`；场景用 `SCENE`、道具用 `PROP`、关键图用 `KEYFRAME`、身份图用 `CHARACTER`、造型图用 `CHARACTER_LOOK` 或兼容 `CHARACTER_REFERENCE`，普通上传图用 `UPLOAD`。
- 造型图明确 `characterId` 和当前 `lookId`，来源造型与人物归属一致；不能把人物身份 ID 填成造型 ID。上传图也可显式弱绑定人物/造型。
- `usageRole` 表示本镜用途；人物细分约束由 `referenceRole=IDENTITY/LOOK/COMBINED/POSE/STYLE` 表达。不要把 `IDENTITY` 当成 `usageRole`。
- 可见人物通常为 `SUBJECT`；第一人称视角人物或画外人物可用 `NON_SUBJECT`，同时在剧本中明确视角与可见范围。画外人物图不强制这个人物出镜，不创建其可见主体。
- 关键图来源仅用下表七种用途。选项以当前工具 Schema/字典为准，不编造代码。
- 平台上限 9 张图片；使用满足需求的最小充分组合。`refImages[0]` 对应 `<Picture 1>`，后续顺延。顺序改变时一起更新提示词，不留空槽或按资产类型另行排序。
- 最终提示词按图号说明约束对象，例如“Picture 1 约束林岚的身份与当前服装；Picture 2 约束会客厅门窗位置和木质陈设”。多人图明确每个角色的视觉特征与相对位置，不能只按数组顺序猜人物。

## 关键图的七种用途

| `usageRole` / 资产默认 `frameType` | 如何使用 |
| --- | --- |
| `FIRST_FRAME` | 开场画面约束；从图中状态开始后续动作，不提前展示动作终点。 |
| `KEYFRAME` | 中间必须出现的关键画面；交代此前动作与之后变化。 |
| `LAST_FRAME` | 结束画面约束；确保起始到结束在时长内物理可达。 |
| `EDITED_KEYFRAME` | 使用编辑后的目标画面；说明保留区域及已明确修改的内容。 |
| `COMPOSITION_ANCHOR` | 参考构图、主体比例、空间关系，不要求视频逐像素复现某帧。 |
| `STORYBOARD_REFERENCE` | 参考故事板的叙事/镜头关系；多格是规划，不能默认生成分屏或复制人物。 |
| `SHOT_PLANNING_REFERENCE` | 参考机位与调度规划；将示意转译成真实画面，不默认保留箭头或标注。 |

前四种约束具体画面，后三种提供构图或规划依据。不要把所有关键图都当作首帧，也不要把镜头结束状态强塞到开场。

## 首尾帧与连续镜头组

首帧写“动作开始前此刻可见的状态”，尾帧写“动作结束后此刻可见的状态”，视频提示词写两者之间的连续变化。参考图用于制备帧图时，先核验合成帧的人物、造型、环境和构图，再将其作为视频端点。

同组、时空连续且构图适合时，可在工作台引用**上一镜已选视频的真实尾帧**作为当前首帧。并非上一镜配置的首帧图，也不是上一镜尚未验证的目标尾帧。平台按组内 `(sortOrder, shotNo, id)` 找直接前驱，不跨组或跳过无视频镜头。

需要向已完成的下一镜衔接时，首尾帧模式可引用**下一镜已选视频的真实首帧**作为当前尾帧；同样只取同组直接后继且必须已有视频。不要同时安排两个尚未生成的镜头互相依赖，先完成一个可用锚点。

引用是当次 Take 的图片快照。来源视频重生成或重选候选后，应核验并重新提取需要更新的引用，下游不会自动变成新构图。检查手持物、脸朝向、视线、步态、光照与镜头轴线，再决定是否续接。

换机位、反打、时间跳跃、地点变化时不机械复用同一帧；保留身份、服装、环境布局和道具状态，为目标机位重新准备画面。尾帧是连续性资料，不是每一镜通用的首帧。

参考模式也可在工作台提取上一镜视频尾帧并新建场景资产；这是素材创建流程，不会自动把它设为本镜首帧。图中若有人物，应按实际内容说明其保留/忽略职责，完整人物环境关键画面通常更适合用关键图表达，不把偶然的旧人物固化为通用空场景。

## 多视图与参考声音

人物三视图/设定图的多个面板表示同一人物，提示词明确不复现面板、不生成人物分身。服装细节参考也不意味着视频必须切到每个细节特写。

人物音色来自身份资产的 `voiceSampleUrl`；`VOICE_TIMBRE` 只借声音特征，不复读样本台词，新台词来自当前 `scriptContent`。参考音频最多 3 段，已知时单段 2–15 秒且总长不超过 15 秒，以模型实际限制为准；未知时长不编造。`refAudios=[]` 是明确不使用参考音频，不能自动补回，也不意味着关闭对白或环境声。
