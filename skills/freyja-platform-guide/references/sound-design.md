# 声音设计与空间连续性

编写或修改镜头剧本、视频提示词、对白和声音参考说明时读取。以已确认剧情、人物走位和环境为依据设计听觉空间；下列规则是制作指导，不代表视频模型已实现精确声像或自动混音。模型段落和对白标签仍按 [H3 接入约定](h3-integration.md) 及当前模型 Skill 编写；角色样本的选择与处理见 [配音中心流程](dubbing-center.md)。

## 先确定听点和声源

- 先说明观众从哪里听：通常采用与当前机位相容的客观听点；明确需要主观听觉时，采用指定人物的听点。不要因视觉特写、推镜或焦距变化就自动认为耳朵贴近了声源。固定、跟随或改变听点都应有叙事依据。
- 对重要声音说明“谁/什么发声、相对听点的方向、远近、是否移动、是否隔着障碍、何时开始/结束”。无需给所有背景声逐一编号，也不编造剧情未确定的精确距离或位置。
- 有位置的画内和画外声应有相应方位：例如左侧近处对白、右后方远处车流、门外走廊中的呼喊。左右以前述听点为准，前后由距离、清晰度、反射与遮挡共同提示，不把“后方”冒充单纯左右声道参数。
- 声源在世界中的位置应连续。反打、越轴、相机转向或听点变化时，重新核对其相对方向；不能无缘无故左右跳变，也不要求所有反打机械交换声道。单声道或模型不能可靠定位时，保留文字空间关系，以远近层次和音色区分，不承诺精确环绕声。

## 远处轻，近处响；进出画不等于远近变化

- **同一声源、相同发声力度和相近环境下，近处通常更响、更清晰，远处通常更轻、细节更少，高频更弱。** 室内远声的直达声比例通常下降、反射感更明显；开阔室外不能机械添加室内长混响。
- 分开描述发声力度与听到的响度：远处大喊可以比近处耳语响，远处爆炸也可能压过近处脚步。人物情绪、喊叫和设备扩音均按既定剧情处理，不能一律把所有远声压得听不见。
- 靠近时音量与清晰度逐步增加，远离时逐步衰减；横向经过时方位随轨迹平滑移动。变化随真实走位与听点发生，不套固定增益、固定距离阈值或每秒同样的淡变。
- **进入画面不必突然变响，离开画面不必立刻消失。** 固定听点下人物从画左走到画右、距离基本不变时，主要改变方位，响度可基本稳定；人物退入远处走廊时才按远离及遮挡减弱。声源在画外接近，可先听到声音再看到人物。
- 多普勒音高变化只在运动速度和情境支持时考虑，例如车辆快速掠过；普通慢步走近不能无依据地升降调。

## 遮挡、空间与声音载体

- 墙体、门窗、转角及身体朝向会改变可懂度、频谱和响度。隔门人声可更闷、细节更少；开门可逐步恢复直达声，关门可逐步变闷，但这些动作必须已在剧本中发生，不能为了声音效果新增开关门事件。
- 区分小房间、空旷大厅、狭窄走廊与开放街道的反射、尾音和环境底声。延续已确立的声学空间，不给每条对白叠加相同回声，也不把安静场所理解为完全数字静音。
- 电话、对讲机、广播等声音来自实际可听的设备或明确的叙事听点。区分“从现场手机扬声器听到的远端人声”和“叙事上切到远端通话者”，避免同一声音同时以干声与设备声重复播放；不让远端角色因发声而错误出现在画内。
- 旁白、内心独白与现场画外对白分别处理。现场画外对白保留其空间位置与传播关系；非现场旁白/内心独白按创作者要求保持稳定可懂，不因画内人物走远而自动变小，不默认套房间混响或左右跑动。

## 对白、动作与混音层次

- 需要观众听清的对白优先保证可懂度，保留人物音色、情绪、语速和原文。环境声与音效在对白下适度让位，不能用持续轰鸣、混响或过度降噪盖住关键台词；剧情明确需要听不清或强噪声压制时保留该表达。
- 动作音效应与画面因果同步：脚步对应落地，碰撞对应接触，摩擦对应持续运动，停止后不继续循环。音色与已知材质、力度、重量和表面相符；不因手持某道具就擅自添加操作音，不给静止物体配碰撞或脚步。
- 多人发声时明确说话人、对白轮次、重叠范围和各自位置；默认不凭空添加群众议论、低语、笑声、喘息或旧试音台词。听者未发声时不误对嘴。
- 区分前景对白、中景动作和背景环境，避免所有声音同样近、同样响、持续满铺。声音密度随当前动作与空间需要变化；张力不等于每次切镜都加低频轰鸣、冲击音或转场音。
- 默认不加背景音乐，按当前平台约定保留 `non_diegetic_music` 并写 `N/A` 或模型要求的无音乐表达。用户明确需要配乐时再加入，不把配乐藏进环境声或音色参考中。

## 跨镜头衔接与参考素材

- 同一连续场景的环境底声、设备持续声和动作余响自然接续，不能每个短镜头都重新起一遍风声、机械声或房间底噪。跨镜对白、先声后画或画切声留可用于既定叙事，不擅自新增台词或重复播放同一句。
- 切到另一空间时按故事建立声学变化；相邻镜头音量、底噪和音色应协调，必要时设计短淡变或环境声桥。它们是生成/后期意图，不能声称保存提示词后平台已完成跨视频混音。
- **可复用音色样本与镜头空间混音分开。** 基础声音保持无特效；优先复用同角色且情绪、特效合适的已有样本。不要仅因人物在本镜头中更远、更偏左或刚出画，就为每个镜头重生配音或修改所有镜头共用的音色记录。
- 使用 `reference` 时在提示词中表达本镜头的远近、方向、遮挡和对白，不复制样本旧台词及无关背景。设备效果已有成品时避免再次叠加同种处理。`fully_copy` / `partially_copy` 必须符合用户明确要求；精确复制的原音轨若与目标空间冲突，应说明并在授权范围内准备合适素材，不能暗中改为另一参考关系。
- 只使用当前模型/工具真正支持的参数。自然语言中的“从左后方传来、渐近、隔门低闷”是声音意图，不是可随意添加的 JSON 字段；不虚构声道、声像、自动增益、混响或逐秒音量接口。FFmpeg 处理须先查询实际滤镜和参数，不覆盖其他镜头引用的录音。

## 写法示例与成品验收

示例只展示声学描述，不构成新增剧情或固定模板：

> 听点固定在室内门边。已在剧情中发声的人从右后方走廊靠近，脚步先轻而模糊，随距离缩短逐步更清晰、更响，保持走廊反射。人物进入画面时不额外跳增音量；停下后脚步停止。对白仍用当前剧本原文，环境底声保持低层连续，无背景音乐。

写入时：把说话人、台词、语气、动作与关键声音事件自然融入 `scriptContent`；把相同声音事件的空间和层次映射到当前模型的视频提示词。H3 对白留在规定的多模态正文，`overall_soundscape` 说明环境、音效和总体听觉空间，避免在两处重复台词引起二次发声。静态图片提示词不承载声音时间线。

验收时实际试听成品，核对方位/走位、远近和遮挡变化、对白归属及可懂度、口型/接触同步、底声连续和意外配乐；留意削波爆音、切点咔哒、尾音截断、重复音效及过强声像造成的听觉不适。需要时检查耳机/扬声器与单声道兼容性。无法播放或无法检查声道时如实说明未验收，不能仅凭提示词或波形声称已经听过；发现问题按实际能力修正，不承诺模型一次生成必然达标。
