# 镜头剧本、制作流程与验收

## 剧本如何写出可执行的表演

把当镜动作、对白、旁白与表情统一写入 `scriptContent`，用稳定的人名区分说话人。依次交代：开始状态 → 触发事件 → 可见反应/动作 → 结束状态。描述服务于当前镜头，不重复整段人物传记或场景百科。

有依据时明确：

- 人物在画内还是画外，左/右/前/后位置、朝向、目光落点及彼此距离。
- 表情的可见表现和变化过程，例如眉心收紧、目光从信封抬向来客、嘴角绷住；情绪变化由哪个动作或哪句台词触发。
- 动作顺序、手与物体的关系、起点终点；同时发生的动作并写，不无故延长总时长。
- 对白原文、说话人、自然停顿和表达方式。内心独白或旁白明确标识，不能让画中人物替旁白开口。
- 必要自然环境声与动作音效。声音可在画外，画外有声不代表画内必须多一个人物。

不要只写“她很难过”就让模型任意发挥。也不要给每个情绪都堆满颤抖、流泪、咬唇等互相抢戏的动作。结合景别选择能看清的一两个关键表演；远景依靠姿态与调度，近景才适合微表情。

仅当原文或创作者授权创作时补充表演细节。忠实改编任务中不把推测当事实、不增写新台词或剧情转折；未说明的状态可留空。表情描述应与人物动机及前后镜一致，不能每镜随机重置情绪。

以下是写法示例，不可直接套入其他故事或当作真实角色资料：

> 林岚站在会客厅桌边，右手压着桌上的信封，目光停在封口。门外传来两下敲门声，她抬眼看向画右的门，眉心轻收，嘴角绷住；手仍压住信封。林岚低声：“进来。”镜头结束时她保持朝门的视线，信封未移动。环境只有轻微风声与敲门声，无背景音乐。

参考图固定脸、衣服和会客厅结构；剧本决定当前眼神、动作、手持状态和台词。视频提示词将两者组合，不能仅写“按图片生成视频”。

## 连续性与合理拆镜

为同组镜头维护一份精简状态：人物位置/朝向、当前造型、手持道具、道具位置/状态、已完成动作、当前情绪和视线目标。下一镜从前镜结果或明确切换后的状态开始。

保持视线与运动方向可读：门在人物哪侧、人与人的轴线、谁朝谁移动。需要越轴或改变方向时安排有依据的机位变化或中性过渡，避免无说明左右翻转。状态由 AI 从原文/剧本和已确认素材提取，不交给 Java 猜测。

按完整动作与自然台词估算 `duration`。普通动作常见 3–5 秒，舒适长镜头可参考 7–8 秒；预计超过 8 秒时寻找完整动作、对白轮次或叙事转折拆镜。不要截断一句话、把一次递物拆成多个碎镜，也不为凑时长添加慢动作或空等。保留创作者明确要求的长镜头，再核实所选模型限制。

首尾状态要物理可达：坐着的人不能毫无过渡在尾帧变到房门外，右手物体不能无说明跳到左手，单镜时长内不能塞入过多空间跳转。景别/运镜未决定时可保持 `AUTO` 及对应锁为 `false`，已有锁遵循创作者意图。

## 平台制作流程

1. 读取项目与目标范围，保留画幅、风格和既有设定。新建项目先读取启用画幅选项；未指定则询问，明确授权 AI 选择时优先启用的 `16:9`。
2. 建立或复用剧集、场次、镜头组。整理人物身份与当前造型、场景、关键道具；相同身份不因别名重复创建。
3. 按完整叙事事件写每镜剧本和时长，明确人物造型与场景/关键图关联。业务草稿默认值不代表最终创作意图。
4. 读取视觉参考指南，为每镜选择模式和最小充分的图像组合。缺图时先准备或标注待制作；生成后检查实际图像，再上传和关联真实 URL。
5. 生成最终视频提示词。H3 首尾帧按对应技能三段式填写 `videoPrompt`；参考模式按六段式填写 `prompt`，明确图号和可选音频号。时长、剧本、参考职责和提示词须一致。`DirectorPlan` 是可选高级数据，常规外部工作流不要求伪造它。
6. 保存并读回核对。使用真实生产能力生成视频；返回任务 ID 仅代表已提交，完成后检查视频。仅有 MCP 业务工具时交付已就绪分镜并说明尚未执行渲染。
7. 从历史 Take 选择合适候选；改选后检查受影响的首尾续接。超分或补帧应在内容、表演和连续性已合格后进行，不能用后处理修复错脸、错装或剧情错误。

图片上传采用当前工具目录提供的 `prepare_asset_image_upload → 真实二进制直传 → complete_asset_image_upload`，再关联返回的正式 URL。上传图像不等于已绑定人物或分镜。不要在工具参数里塞图片 Base64，不编造 MinIO 路径；不把过期的旧版上传工具名当作可用能力。

## 每镜交付检查

- **叙事与表演**：镜头有清楚目的，动作、对白、表情和时长匹配；画内/画外人物及说话人明确。
- **人物与环境**：身份和造型正确，空间布局、光照方向、道具与前镜相容；关键图内容清晰可用。
- **素材与模式**：首尾输入或参考数组适用于所选模式；主视觉关联互斥；图号与最终提示词一致；不重复叠加相互矛盾的素材。
- **声音**：音色属于正确角色，不复用音色样本的旧台词，不把画外人物强行入画；默认无背景音乐且保留模型要求的音乐段落。
- **持久化**：读回实际 `generationMode`、`duration`、对应视频提示词、帧 URL/媒体数组及 `characterRefs` 的真实人物/造型 ID；不是只检查提交前的草稿。
- **产物状态**：如实区分待制图、已关联素材、提示词就绪、渲染中、已生成、已人工/AI 检查。说明发现的具体问题，不能承诺参考图必然消除漂移。

回读或视频检查发现问题时，只修改证实有问题的部分，使用最新指纹。交付给用户时简述已完成范围、待制作镜头及关键取舍，不把内部技术字段堆到创作者操作流程里。
