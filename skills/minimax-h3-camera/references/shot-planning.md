# 拆镜、镜序与连续性

## 先有叙事单位，再有镜头数量

先从当前已确认的剧本识别完整事件：动作目标、对话轮次、信息揭示、人物反应或观察段落。先说明观众要知道什么、什么时候知道，再选择一个镜头还是多个镜头。展示、风景或观察任务可以保持一个稳定观察，不为满足模板硬造反转、高潮或冲突。

不要先规定“每句一句镜头”“每镜四秒”“固定远中近三连”，再回头填剧情。景别变化要承载有效信息；有充分可读性的一镜可以比三个碎镜更好，明确要求的剪辑节奏和镜数则优先遵循。

## 什么时候保持一镜

- 同一目标下的准备、执行、结果，尤其是拿取、交接、放置、握持和机械操作，需要观众看懂接触关系时。
- 只需略微靠近、跟随、揭示或转移注意力，现有机位通过连续运动或调焦即可表达时。
- 悬念、喜剧时机、人物犹豫或空间关系需要观众持续观察时；没有“大动作”不等于应该切镜。

“一个动作链”可包含连贯的多个步骤，不把每个动词都拆成一镜，也不把多个人的相互作用压成单人静态姿态。可并行的动作在同一时间内发生；叙述环境状态不另计动作时长。

## 什么时候切镜有价值

| 切镜依据 | 应核对的内容 |
| --- | --- |
| 需要新的叙事信息或视点 | 本镜能看见什么新的证据、人物反应或空间关系？是否提前泄露后续信息？ |
| 对白轮次 / 有意义的反应 | 切点服务说话者或听者当下的动作，不是每说一句必反打；台词完整可懂 |
| 空间变化或遮挡 | 原机位是否无法看清关键结果？新机位是否建立必要地理，而非随机换角度？ |
| 动作完成边界、明确的下一目标 | 前镜结果是否可被下一镜承接？需要承接的动作阶段有没有被省略或重复？ |
| 创作者要求的蒙太奇或时间转换 | 新时空和关系是否已在故事中成立？不借转场擅自增加事件 |
| 实际生成时长 / 负载限制 | 找到自然断点，并说明这是部署或模型条件，而非宣称该动作本来就必须碎切 |

机位变化可用于有意义的切镜；禁止的是没有信息增量的机械碎切。推近到手部不够清楚时，可以安排有依据的接触特写，同时确保动作阶段衔接。

## 时长按完整表演推导

先估完整原台词与自然动作：对白及不能重叠的动作相加，可并行部分共用时间。根据已有语速、情绪和动作复杂度判断，不用通用“每字固定秒数”替代实际估时。不删台词、加速、拉长停顿或套慢动作以满足时长桶。

普通动作常见 3–5 秒，较长镜头可参考 7–8 秒。预计超过 8 秒时积极寻找可读动作边界、对白轮次或叙事节点，保留连续动作的目的与结果；参考值不构成目标平均时长。用户明确要求长镜头时保留创作意图，先核实执行条件。

当前 FREYJA guide 说明 10 秒及以上容易 OOM；提交前核对实际工作流、帧数对齐、参考输入及负载，不把 9.9 秒当通用安全解法。资源不足时给出自然拆镜或可用算力方案，不擅自提高并发反复尝试。模型接受的时长范围另行读取，不从本 Skill 推导接口参数。

## 每次切镜做一次状态交接

上一镜的真实末态与下一镜计划起态至少核对：

- 谁在何处、朝向哪里、看谁，人物进出画是否与实际路线一致；
- 物件由谁哪只手持有、接触点、开闭和完好状态，有没有无过程的换手、复原或消失；
- 动作处于哪一阶段，前镜已经完成的动作是否在后镜又从头执行；
- 轴线侧、屏幕运动方向、视线高度和遮挡关系，新机位是否仍符合空间；
- 时间、照明、环境底声及对白是否连续，有无重复、漏词和无依据的音量跳变。

交接表是创作辅助，不是 API 新字段。例如可以在任务说明中记录“前镜右手已松开、后镜左手仍持物”，但不得把未支持的状态键发给业务接口。

## 轴线与剪辑语法是依据，不是机械禁令

常规对话和动作覆盖保持已建立的轴线、屏幕方向与视线匹配。确需越轴时，用连续跨轴运动、中性机位或新的空间建立使关系可读；已有创作者明确的表现性跳切应保留其意图。

同主体相邻机位差异过小容易显得跳动，可改变取景或切点来改善，不把“必须精确 30°”当模型参数或所有剪辑的绝对规则。画右出、下一镜从画左进入是某些连续行进覆盖的常用匹配，不应覆盖真实路线、回头或明确转向。

动作匹配可在运动中切：关键在于相位、方向与物件状态对应，不是每镜先停住再开下一镜。J/L cut 可作为声音衔接计划，实际后期混音及跨请求同步须由已有工具实现，不承诺 H3 的独立生成文件天然无缝。

## 原创判断示例

1. **递杯，完整动作约四秒**：目的在于看清交接，优先固定双人中景，伸出、接触、接稳、松手在同镜完成。不要仅为凑“全景—手部—表情”拆成三次生成。
2. **认出信件上的关键内容，随后听者改变决定**：若剧本确有该信息，可先让观众看到内容再切听者反应；切镜依据是信息与反应，而非单纯焦距变化。文字内容必须来自剧本，不自行补写。
3. **原台词自然说完约十一秒**：先核实当前链路。需要拆分时在完整语义单元或对话轮次处分镜，保留全部原文；无自然断点时说明限制，保留长镜要求并选择可执行方案，不把末句删掉或强行赶读。
4. **同一跟拍延展为两个生成片段**：不是新增叙事切镜。从已接受尾帧、动作阶段和实际摄影方向继续，第二段不重新从静止起步；没有尾帧及延展能力时不声称实现一镜到底。

## 完成条件

范围内的剧情和原台词都有承载，镜头之间的职责不机械重复，切点有理由，动作和空间可接续，时长可自然表演，实际素材支持起落幅。只修改受影响的镜头；新增、拆分或合并时保留未受影响的业务 ID，并说明哪些下游提示词需更新，不擅自重新生成媒体。
