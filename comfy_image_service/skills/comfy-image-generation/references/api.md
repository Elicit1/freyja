# CLI and API reference

## Connection

The terminal client requires only Python 3.10+ and its standard library. Configure:

```text
COMFY_IMAGE_BASE_URL=http://127.0.0.1:8011
COMFY_IMAGE_API_KEY=<private service token>
```

Alternatively use a private JSON file:

```json
{"base_url":"http://127.0.0.1:8011","api_key":"<private service token>"}
```

Pass `--config /absolute/path/client.json` **before** the subcommand, or set `COMFY_IMAGE_CONFIG` to its path. Do not commit the file. The repository client also discovers `comfy_image_service/.client.json`; a distributed Skill does not contain credentials.

`base_url` is the service origin, without `/v1`. The service runs in the user's local WSL Docker and publishes only `127.0.0.1:8011`; the CLI runs on Windows or in WSL. The repository's `start.ps1` starts this independent local container. GPU execution uses the already configured ComfyUI backend.

## Commands

```bash
python scripts/generate.py capabilities
python scripts/generate.py readiness
python scripts/generate.py t2i --tier standard --prompt "A moonlit botanical garden" --mp 4 --aspect-ratio 16:9 --no-expand --output garden.png
python scripts/generate.py i2i --tier fast --image source.png --prompt "Edit <Picture 1>. Change daylight to golden-hour lighting; preserve the subject and composition." --mp 1 --no-expand --output edited.png
python scripts/generate.py status JOB_UUID --output recovered.png
```

| Parameter | Values / default | Selection |
| --- | --- | --- |
| command | `t2i`, `i2i` | New image or edit an existing image |
| `--app` | `minimax-h3-image` | Discover other registered apps with `capabilities` |
| `--tier` | `pro`, `standard`, `fast`; default `standard` | INT8 / W4A8 / Q4_K_M respectively |
| `--prompt` | Required, 1–32000 characters | Description or reference-image editing instruction |
| `--mp`, `--megapixels` | 0.1–20; default 4 | Target area; 1 MP means 1024×1024 pixels |
| `--aspect-ratio` | t2i: `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `9:16`, `16:9`, `21:9`; default `1:1` | i2i accepts `original` and preserves its input ratio |
| `--image` | Required local path for i2i | PNG, JPEG, or WebP; at most 25 MiB and 40 source MP |
| `--no-expand` | Recommended for every generation unless the user requests expansion | Turns off expansion and preserves input text; CLI/service defaults remain ON when omitted |
| `--seed` | 0–9007199254740991; random by default | Reproducibility within the selected model and workflow |
| `--output` | Local image filename | Defaults to `outputs/JOB_UUID.png`; does not overwrite by default |
| `--overwrite` | Explicit flag | Allows replacing an existing output |
| `--wait-timeout` | Seconds; default 1800 | Client polling deadline; does not cancel a GPU job |
| `--idempotency-key` | 1–128 characters; generated by CLI | Use the identical key and parameters to recover an ambiguous submission |

Dimensions are aligned to 32, so actual pixel area can differ slightly from the target. Do not pass steps, CFG, sampler, denoise, negative prompt, or arbitrary model filenames. H3 Image is configured for six steps, CFG 1, Euler/Simple, denoise 1. Tier selection is the supported model control.

## Output contract

Progress goes to stderr. A successful command prints one JSON object to stdout:

```json
{"job_id":"UUID","status":"succeeded","app":"minimax-h3-image","mode":"t2i","tier":"standard","seed":42,"effective_prompt":"...","images":[{"path":"/absolute/output.png","width":2048,"height":2048}]}
```

A nonzero exit code is a failure or incomplete job. Preserve any printed job ID. `status JOB_UUID` checks/downloads that job without new submission. Check the actual output before claiming an edit met the user's request.

## HTTP interface

All `/v1/**` routes require `Authorization: Bearer TOKEN`, including image downloads and Skill downloads. `/health` is public. This independent REST API uses asynchronous jobs; it is not the existing FREYJA gateway's OpenAI endpoint.

- `GET /v1/capabilities`: discover parameter schema, apps, tiers, and limits.
- `GET /v1/readiness`: check installed nodes and model filenames; this does not certify VRAM capacity.
- `POST /v1/uploads`: raw image bytes, returns `{id,width,height,sha256}`.
- `POST /v1/t2i`: JSON `{app?,tier?,prompt,megapixels?,aspect_ratio?,expand_prompt?,seed?}`.
- `POST /v1/i2i`: same fields plus `image`, an upload ID or a base64 PNG/JPEG/WebP data URI. HTTP image URLs and server file paths are not dereferenced.
- `GET /v1/jobs/JOB_UUID`: current state, backend prompt ID, result, and error.
- `GET /v1/jobs/JOB_UUID/images/0`: authenticated image bytes.
- `GET /v1/skill.zip`: portable Skill package without credentials.

Example body:

```json
{"app":"minimax-h3-image","tier":"standard","prompt":"A red ceramic teapot","megapixels":4,"aspect_ratio":"16:9","expand_prompt":false,"seed":42}
```

Generation returns HTTP 202 with a durable job ID. Poll until `succeeded`, `failed`, or `unknown`. Results include authenticated image URLs. States `queued`, `preparing`, and `running` are pending; `unknown` requires checking the existing job, since the GPU may still be working. Restarted services resume persisted running jobs by their backend IDs. They never resubmit an uncertain backend submission automatically.

Use `Idempotency-Key` for programmatic submissions. Reusing a key with changed parameters returns HTTP 409. Invalid profile, resolution, aspect ratio, unknown fields, or missing image returns 422; wrong credentials return 401; a missing service key returns 503. Resolve the cause before retrying. Do not retry render failures as an unlimited loop.
